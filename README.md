# Trilingual PDF Converter

## 開発背景

PDFをそのまま大規模言語モデルへ入力すると、文書全体の構造情報が十分に活かされないまま大量のTokenを消費し、改行や段組みの影響で文章のレイアウトも崩れやすくなります。本プロジェクトは、まずPDFをローカルで軽量なテキストデータへ整形し、必要な部分だけを扱いやすくするために開発しました。

## 主な機能

- PyMuPDFによるPDFテキスト抽出とNFKC正規化
- 日本語かな、CJK漢字、英単語のインテリジェントな認識・統計
- 文字種に応じた主言語判定
- 日本語・中国語の行末をシームレスに連結し、英語の行折返しには空白を補う改行修復
- 段落と小見出しの構造をできる限り保持
- Markdown、Word（.docx）、構造化JSON、純粋なTXT、全形式ZIPへの変換
- Word出力では東アジア文字に `Yu Gothic`、西欧文字に `Calibri` を指定
- ブラウザ上でのドラッグ＆ドロップ、リアルタイム三語統計表示

## 三語認識の特徴

ひらがな・カタカナを日本語かなとして数え、CJK統合漢字を漢字として数えます。英語は連続したラテン文字列を単語単位で数え、これらの比重から文書の主言語を推定します。混在文書でも、言語ごとの傾向を短時間で確認できます。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```

ブラウザで http://127.0.0.1:5000 を開いてください。アップロードしたPDFはサーバー上に保存せず、リクエスト中にメモリ上で処理します。
